# Сөйлеу әлемі

Тахилалияны түзетуге арналған интерактивті логопедиялық ойындар әлемі (Playful kids дизайны).
5 бағыт, 18 ойын, 54 деңгей («Сөйлеу әлемі» сценарийі бойынша). Тәуелділіксіз: таза HTML, CSS, JavaScript.

## Іске қосу

Микрофон мен камера тек қауіпсіз контекстте (`https://` немесе `localhost`) жұмыс істейді.
Файлды қос шертіп ашу (`file://`) жеткіліксіз, сондықтан жергілікті сервер қос:

```bash
cd kids-speech-world
python3 -m http.server 8000   # содан кейін http://localhost:8000 ашу
```

Кез келген статикалық хостингке (GitHub Pages, Netlify, т.б.) жүктеуге болады, олар https беріп тұрады.

## Файлдар

- `index.html` — бет қаңқасы
- `styles.css` — дизайн
- `data.js` — барлық ойындардың мазмұны (мәтін, суреттер, деңгейлер)
- `core.js` — дыбыс, дауыс, микрофон, камера, сақтау
- `app.js` — экрандар және ойын механикалары

## Құпиялық

Микрофон қосулы кезде ойын таныстырылымынан бастап аяқталғанға дейін дыбыс жазылады. Жазба тек браузер жадында (IndexedDB) сақталады, серверге жіберілмейді; логопед бөлімінде тыңдауға, жүктеуге, өшіруге болады. Камера бейнесі жазылмайды.
Прогресс тек браузердің `localStorage` жадында тұрады.

## Суреттер мен бейнелер

- `img/apple.jpg` — сценарийдегі нақты фото. Басқа фото қосу үшін `data.js` ішінде `pic: 'photo:img/файл.jpg|🍎'` деп жазыңыз (файл табылмаса, эмодзи көрінеді).
- Нұсқаулық «бейнежазбалар» — кодпен жасалған анимациялық үлгілер. Нақты MP4 қосу қажет болса, `app.js` ішіндегі `demoCard` функциясын өзгертіңіз.
- Сөйлеуді тану (SpeechRecognition) әдепкіде өшірулі, ересек рұқсат берсе ғана қосылады.
